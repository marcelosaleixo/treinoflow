# ETAPA 97 — Ações Recomendadas por Aluno

## Objetivo
Transformar o bloco Atenção Hoje em um painel operacional.

## Implementação
- Cada aluno prioritário recebe título de ação conforme o risco.
- O primeiro sinal de risco é exibido como motivo principal.
- O Personal pode abrir o Perfil Inteligente.
- O Personal pode registrar contato diretamente no CRM.
- Quando houver telefone válido, é oferecido WhatsApp com mensagem pré-preenchida.
- O Personal pode abrir os treinos do aluno para revisão.

Nenhuma ação é enviada ou executada automaticamente. O Personal permanece no controle.
